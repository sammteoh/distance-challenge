# Distance Challenge Analytics Dashboard
An interactive data dashboard created to track, calculate, and visualize participant progress for the 2024-26 Distance Challenge at The Primacy Collegiate Academy.

## Features

- **Dynamic Leaderboards:** Automatically parses and sorts participant logs by total mileage and completion metrics.
- **Progress Tracking & Analytics:** Visual charts tracking various participant metrics including distance run, improvement by week, and consistency.
- **Data Parsing:** Reads and transforms CSV logs into structured, interactive dashboard UI elements.
- **Minimalist Layout:** Clean, intuitive interface built to render cleanly on desktop browsers.

## Tech Stack & Concepts

- **Frontend:** JavaScript (ES6+), HTML5, CSS3
- **Data & Logic:** Client-side data parsing, array operations, dynamic DOM rendering, and state management.
